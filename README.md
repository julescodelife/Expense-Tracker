Expense Tracker

A simple expense tracking application built with HTML, CSS, and Vanilla JavaScript.

Overview:

Expense Tracker allows users to record, view, and manage their daily expenses while automatically calculating their total spending.

This project was created as part of my 180-Day Full-Stack Developer Learning Journey.

Features:
Add expenses with a name, amount, and category.
Display expenses dynamically.
Delete individual expenses.
Automatically calculate total expenses.
Format amounts using Philippine pesos (₱).
Validate expense names, amounts, and categories.
Display an empty state when there are no expenses.

How to Run
Download or clone this repository.
Open the project folder.
Open index.html in your browser.

Current Limitations:
Expenses are stored in memory and reset when the page is refreshed.
Data persistence has not yet been implemented.
Editing expenses is not yet supported.
Category filtering and sorting are not yet implemented.
